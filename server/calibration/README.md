# SENTINEL Analyzer Calibration Corpus v1

This directory documents the deterministic synthetic fixture corpus used by `npm run calibrate`.
The fixture bytes are generated by `scripts/calibrate-analyzers.ts`; their SHA-256 hashes are pinned in that script so accidental fixture drift fails calibration.

| Fixture | Ground truth | Expected archive analyzer outcome |
|---|---|---|
| `zip-clean-small` | Valid benign synthetic ZIP | `completed_no_detections` |
| `zip-path-traversal` | Unsafe `../` entry path | `finding` with `archive-path-traversal` |
| `zip-expansion-limit` | Declared expansion exceeds policy | `finding` with `archive-decompression-bomb` |
| `zip-truncated-eocd` | Truncated ZIP end record | `inconclusive` with `archive-structure-anomaly` |

The harness separately tests live ClamAV using the standard EICAR antivirus test string. Missing ClamAV is reported as `blocked`; it is not treated as a pass. Use `npm run calibrate -- --require-live-tools` to make missing live ClamAV fail the command with exit status 2.

## Interpretation

This corpus is a deterministic regression suite for selected ZIP metadata rules. Its detection-rate and specificity figures are descriptive only and **must not** be represented as real-world malware-detection accuracy. The corpus has only three positive fixtures and one clean fixture; it does not measure malware family coverage, general document behavior, or false-positive rates on representative user data.

Each future corpus expansion should include a documented fixture provenance, explicit ground truth, expected analyzer outcomes, stable hashes where generated bytes are deterministic, and a review of false-positive/false-negative implications.

## Stage 13 — cross-module trust probes

The Stage 13 harness adds tests against production code paths, not lookalike implementations:

- **DOCX:** a minimal benign OOXML document and a document with hidden AI-targeted instructions are passed through `analyzeDocx`. The positive fixture must produce `docx-prompt-injection`.
- **PDF:** a minimal benign PDF is passed through `analyzePdf`. If the required PyMuPDF module is absent, the result is explicitly `blocked`; a missing parser dependency is not interpreted as a clean document and does not masquerade as an analyzer regression.
- **PE boundary:** a synthetic invalid executable header is passed through `analyzeExe` and must be classified `not_applicable`. This is a format-boundary probe, **not** a positive PE threat-detection test.
- **Unicode differential perception:** clean text, a zero-width character, a bidi override, and full-width compatibility characters test the actual `sanitizeUnicode` implementation.
- **Redaction integrity:** a valid output receipt must verify; tampered hash, path-bearing filename, and unverified output must be rejected by the actual `verifyRedactionPayload` implementation.

The report separates `pass`, `fail`, and `blocked`. A blocked PDF probe means coverage was not established. The harness currently does not claim calibrated OCR quality, broad PE threat detection, parser disagreement calibration, or remediation end-to-end verification. Those require a larger, independently reviewed corpus and fixtures with explicit provenance and ground truth.

## Stage 14 — dependency and live-tool prerequisites

The PDF analyzer imports PyMuPDF. Its pinned dependency is now declared in `python-analyzers/requirements.txt`; initialize the dedicated interpreter with `bash python-analyzers/scripts/setup.sh` from the repository root. The server auto-prefers `python-analyzers/.venv/bin/python` when present, while `PYTHON_EXECUTABLE` remains an explicit override. A missing module remains a blocked PDF probe, never a clean pass.

The EICAR live antivirus probe requires the trusted `clamscan` executable and usable signatures. Install ClamAV using the host's package manager, update signatures, and run `npm run calibrate -- --require-live-tools` from `server/`. The `--require-live-tools` flag returns exit status 2 when live ClamAV is unavailable. Calibration in an environment without `clamscan` is intentionally blocked. Do not treat the EICAR fixture as real malware or as evidence of broad malware-family coverage.
