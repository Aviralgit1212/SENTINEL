SENTINEL

Configure the local SENTINEL gateway. The pairing token lives only in this browser profile and is sent solely to the configured localhost endpoint.

Set the same token in the server's SENTINEL_EXTENSION_TOKEN environment variable and configure the extension origin on the server. Minimum 32 characters.

How the guard works

• On supported AI chat sites (chatgpt.com, claude.ai, gemini.google.com), clicking Send or pressing Enter is intercepted and your composer text is inspected locally first. Detected sensitive data can be auto-redacted in the composer — you review and re-send.

• Attached files are inspected fail-closed: blocked or indeterminate attachments are never submitted; clean ones require one more click of Send.

• On all other sites a single notice tells you protection is not active there.

• To open this dialog later: extensions menu (puzzle icon) → SENTINEL AI Guardian → ⋮ → Options, or the Settings button in the popup.
